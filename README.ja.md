# NTFS 読み取り専用リカバリツール

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語** | [Español](README.es.md) | [Deutsch](README.de.md)

Windows が **RAW** と表示し、開けず、フォーマットを促し続けるような壊れた NTFS ボリュームから、ファイルを取り出すローカル Web ツールです。

生ディスクを直接読み、MFT（マスターファイルテーブル）全体を走査し、各レコードに保存されている「親ディレクトリへの参照」からディレクトリツリーを再構築します。ルートディレクトリ自体が失われていても動作し、元のファイル名とフォルダ構成を保ったまま取り出せます。

**完全に読み取り専用。元のディスクには一切書き込みません。**

## 他のツールで無理でも動く理由

一般的な復元ツールは「ボリューム → ルートディレクトリ → サブディレクトリ → ファイル」という経路をたどります。MFT レコード #5（ルートディレクトリ）が壊れると、その最初のリンクで切れてしまいます。Windows はボリュームを RAW と判定し、多くのツールには空のディスクに見えます。その先へ進めるツールも、シグネチャによるカービングに切り替わるため、ファイル名はすべて失われます。

NTFS のファイルレコードは**自己完結**しています。1024 バイトの各レコードに、ファイル名、親ディレクトリのレコード番号、データが入っているクラスタが書かれています。そこで本ツールはルートディレクトリを完全に無視します。

1. ブートセクタを読み、MFT の開始位置とクラスタサイズを取得
2. `$MFT` 自身のデータランを解決 — MFT も 1 つのファイルであり、数百の断片に分裂して複数のレコードにまたがることがある
3. すべての MFT レコードを順に走査し、「親への参照 + ファイル名」を取り出す
4. 逆方向に集約してツリー全体を再構築

## 機能

- **ルートディレクトリが壊れていても復元できる** — ボリュームが RAW になる最も一般的な原因
- **ファイル名とフォルダ構成を保持** — シグネチャカービングとは異なる
- **すべてのファイル形式に対応** — 写真、動画、文書、アーカイブ。拡張子による絞り込みはしない
- **不良セクタで停止しない** — 各ブロックをワーカースレッドで読み、タイムアウトを設定。読めない領域はスキップして件数を記録
- **ローカル Web インターフェース** — ディスク一覧、診断、スキャン進捗、フォルダツリー、種類フィルター、抽出進捗
- **スキャン結果をキャッシュ** — 開き直しても再スキャン不要
- **フレームワーク不要** — 標準ライブラリの HTTP サーバーと素の JavaScript。ビルド手順なし
- **厳密に読み取り専用** — 書き込みモードで元デバイスを開くコードパスは存在しない

## 動作環境

- Windows（生デバイスへのアクセスは Windows 固有）
- Python 3.8 以上
- `dissect.ntfs` — 任意。`$MFT` の断片化が激しい場合にのみ、データランの解決に使用

## クイックスタート

```bash
git clone https://github.com/createBean/DiskRepairTool.git
cd DiskRepairTool
pip install dissect.ntfs
```

あとは `启动.bat` をダブルクリックするだけです。管理者権限を自分で要求し、依存関係がなければインストールし、ブラウザで画面を開きます。

手動で起動する場合：

```bash
python server.py
```

サーバーは `http://127.0.0.1:8765/` で待ち受けます。

故障したディスクがない場合は `http://127.0.0.1:8765/?demo=1` を開くと、サンプルデータで画面を確認できます。

## 使い方

1. **ディスクを選択** — 型番と容量から故障したドライブを選ぶ
2. **パーティションを選択 → 診断** — ブートセクタと MFT の先頭 16 レコードを調べ、ルートディレクトリが壊れているか判定
3. **スキャン** — MFT 全体を読み、ツリーを再構築。数百万レコードでも数分程度
4. **参照して選択** — フォルダを辿って必要なファイルにチェック。画像が多いフォルダも一覧表示される
5. **抽出** — 保存先を選んでコピー開始。進捗とバイト数がリアルタイムで更新される

## 制限事項

**対応**：NTFS の論理破損 — ルートディレクトリの消失、パーティションテーブルの破損、ファイルシステム構造の破損、停電や安全でない取り外しの後に RAW になったボリューム。

**非対応**：

- **物理障害** — カチカチ音、落下、水没したドライブ。通電せず、クリーンルームでの開盤修理が必要
- **exFAT / FAT32** — ディスク上の構造が異なるため未実装
- **暗号化ボリューム** — BitLocker / VeraCrypt は事前に解除が必要
- **上書きされたレコード** — ファイルのレコードが再利用されたクラスタを指している場合、そのレコードからは復元できません。シグネチャカービングのみ可能ですが、ファイル名は失われます

## トラブルシューティング

**ドライブレターがない。** 管理者として実行すると `\\.\PhysicalDriveN` を開くため、ドライブレターは不要です。昇格していない場合はボリュームハンドルに切り替わり、その場合はドライブレターが必要になります。

**アンチウイルスに検出される。** 想定内です。動作（全ディスクの走査、大量の読み取り）がランサムウェアに似ているためです。ソースは短く監査可能で、デバイスは読み取り専用でしか開きません。

**ビルドした exe が起動しない。** Windows のスマート アプリ コントロールや SmartScreen は、署名のない評価されていない実行ファイルをブロックします。ソースから実行するか、バイナリに署名してください。

**スキャンしても何も見つからない。** まず診断結果を確認してください。ブートセクタが NTFS でない、または MFT のランリストを解決できない場合、物理障害か別のファイルシステムの可能性があります。

---

## 安全性

- プログラムは元のディスクから読み取るだけで、書き込みモードで開くコードパスはありません
- 管理者権限は生デバイスのハンドルを開くためだけに必要です
- 唯一の書き込みは、指定した保存先フォルダに対してのみ行われます
- 復元はベストエフォートです。すべてのファイルを保証できるツールは存在しません
